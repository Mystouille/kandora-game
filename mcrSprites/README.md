# MCR tile sprites

These prebaked 10x5 PNG atlases are generated from the saved tuning in
`../../../scripts/mcr-tile-atlases.json`.

Run `npm run game:generate-mcr-tiles` from the tournament repository root to
rebuild them. The Tenhou tile bodies used as bake inputs remain under
`../tenhouSprites`; MCR face-art provenance is documented in
`../THIRD_PARTY_NOTICES.md`.
